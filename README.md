# 白樺湖レイクサイドホテル山幸閣 ｜ サイトリニューアル（ドラフト）

信州・白樺湖畔の旅館「白樺湖レイクサイドホテル山幸閣」公式サイトのリニューアル案です。
**合宿・団体・サプライズ演出**を軸に再構成した、素のHTML/CSS/JSによる静的サイト。

> ⚠️ これは制作中のドラフトです。掲載中の「お客様の声」は代表例（サンプル）、料金は目安、一部写真はデザイン用のイメージです。公開（本番）前に実データへ差し替えてください。`robots.txt` で検索エンジンのインデックスを抑止しています。

## ページ構成
| ファイル | 内容 |
|---|---|
| `index.html` | トップページ |
| `rooms.html` | 客室 |
